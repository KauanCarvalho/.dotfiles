# Dotfiles

Personal dotfiles focused on a clean, keyboard-driven, terminal-first workflow.

This repository contains my daily-use configuration for shell, editor, terminal
and CLI tools. The goal is to keep everything minimal, readable and reproducible,
without unnecessary abstractions or hidden automation.

---

## What’s included

### Shell
- zsh configuration
- aliases and environment defaults

### Editors
- **Neovim**
  - Lua-based configuration
  - LSP, Treesitter and productivity plugins
- **VS Code**
  - Settings, keybindings and snippets
  - Extensions managed via versioned list

### Terminal
- Kitty configuration
- Gruvbox Dark color scheme

### Multiplexer
- tmux configuration (modular)
- Clipboard integration and sane defaults

### CLI tools
- fzf integration
- Custom helper scripts

---

## Repository structure

```
bin/          → executable helper scripts
config/       → XDG-compliant configs (nvim, kitty, vscode)
tmux/         → tmux configuration (modular)
snippets/     → custom snippets
```

## Installation

The setup script creates symbolic links to the appropriate locations in your
home directory. It is safe to run multiple times.

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/KauanCarvalho/.dotfiles/main/bin/setup.sh)"
```

> ⚠️ Review the script before running it if you want to understand or customize
> the symlink strategy.

---

## VS Code

VS Code configuration is stored in `config/vscode` and linked to the expected
location under `~/.config/Code/User`.

### Extensions

Extensions are managed explicitly via a versioned list:

```
config/vscode/extensions.txt
```

Two helper scripts are provided:

- **Install extensions (dotfiles → machine)**
  ```bash
  bin/vscode-install-extensions.sh
  ```

- **Sync extensions (machine → dotfiles)**
  ```bash
  bin/vscode-sync-extensions.sh
  ```

Both scripts:
- Check if `code` is installed
- Are safe to run multiple times
- Do nothing if VS Code is not present

Extensions are **not installed automatically** by `setup.sh` and must be run
explicitly when desired.
