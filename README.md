# Dotfiles

Personal dotfiles focused on a clean, keyboard-driven workflow.

This repository contains my daily-use configuration for terminal, editor and CLI
tools. The goal is to keep everything minimal, readable and reproducible, without
over-engineering or unnecessary dependencies.

---

## What’s included

- **Shell**
  - zsh configuration
  - aliases and environment defaults

- **Editor**
  - Neovim (Lua-based configuration)
  - LSP, Treesitter and productivity plugins

- **Terminal**
  - Kitty configuration
  - Gruvbox Dark color scheme

- **Multiplexer**
  - tmux configuration (modular)
  - Clipboard integration and sane defaults

- **CLI tools**
  - fzf integration
  - Custom helper scripts

---

## Repository structure

```
bin/          → executable helper scripts
config/       → XDG-compliant configs (nvim, kitty)
tmux/         → tmux configuration (modular)
snippets/     → custom snippets
```

---

## Installation

The installation script creates symbolic links to the appropriate locations
in your home directory.

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/KauanCarvalho/.dotfiles/main/install.sh)"
```

> ⚠️ Review the script before running it if you want to understand or customize
> the symlink strategy.

---

## Cleanup

Removes backup files generated by editors or tools.

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/KauanCarvalho/.dotfiles/main/clean_backups.sh)"
```
